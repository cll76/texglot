# 翻译背景规则

段落翻译的 `paper_context` 来自论文源码中明确标记的原文摘要。「上下文引导」初始默认开启，以下提取规则适用于开启时。

## 开关

新建翻译页面可选择本次任务的模式，模型设置可保存新任务默认值；CLI 用 `--context-guidance` / `--no-context-guidance` 覆盖本次选择，搭配 `--configure` 保存默认值。默认值变动不会影响已经排队或保存的任务。任务详情和 CLI 恢复参数可修改下次重新处理的模式，运行中的任务不能切换。

新建翻译中的开关位于语言选择右侧。悬停或点按名称后的问号查看说明；键盘 Tab 聚焦也会显示，Esc 可关闭。窄窗口按需换行，说明浮层不会增加表单高度，且限制在窗口边界内。

关闭时跳过摘要提取，`user` 消息中不发送 `paper_context` 字段，`system` 消息中也不添加摘要背景相关指令；普通翻译指令、术语表和公式/格式保护仍生效。重试同样遵守关闭状态。

## 提取与长度

- 从选定的主文件开始，按照源码中 `\input`、`\include`（含星号形式）、`\subfile` 的出现顺序读取引用，并限制在原文编译实际加载、可参与正文翻译的文件范围内；不读取未使用的草稿或仅供公式／绘图使用的片段。
- 使用遇到的第一份非空、可读摘要。支持 `\begin{abstract}…\end{abstract}`（以及 `abstract*`，可位于导言区）、`\abstract{…}` 和 `\abstract …\endabstract`。Astronomy & Astrophysics 的五段式摘要合并提取；摘要本身可以引用其他 `.tex` 文件。
- 忽略源码注释、常见命令/环境定义、代码与注释环境。摘要中的数字、公式、引用和文本格式保持原始 LaTeX；只合并多余空白，不用模型概括摘要。
- 背景上限是 **6000 个字符**，包括截断标记 `…`，不是 6000 tokens。超长时优先在接近上限的句末截断，其次尝试词边界，最后按字符截断；请求发送前再次执行相同上限。
- 没有可读摘要时传空字符串，不用正文、附录或任意前几个片段替代。处理记录会说明是否识别到摘要以及实际字符数。

提取过程不运行 TeX，不展开用户宏或对复杂条件分支求值。动态生成的摘要及特殊模板可能无法准确识别。为避免异常输入耗尽资源，扫描最多 200 万源码字符、引用深度最多 32 层，拒绝访问工程目录外文件，循环引用会停止继续展开。扫描限制或不支持的写法只影响可选背景，不阻止正常翻译。

## 请求与缓存

开启时，所有段落共享同一份摘要。系统提示词明确要求把它作为研究主题和术语的参考，只翻译 `paragraph` 字段；摘要与段落都作为文档内容处理。结构校验失败后重新请求时仍携带摘要。

每次请求还提供当前段落未遮盖的原文 `surrounding_source`，用于核对模型名称、日期、数值及其语义归属。它与 `paragraph` 来自同一个原文段落；修复拆分为完整句子时，也只借助该原段核对上下文，不翻译额外内容。这个原文对照不属于摘要引导，关闭上下文引导时仍保留。

缓存同时绑定提示词版本、API 地址、模型、目标语言、术语表、上下文引导开关和实际摘要背景。摘要修改或切换模式会使后续处理使用独立缓存（即使开启时未识别到摘要，也与关闭模式隔离）；相同摘要和设置仍可复用成功片段。旧缓存文件和已生成 PDF 保留，不自动发起重译。使用新版本继续或重新处理旧任务时，不复用旧背景策略生成的段落缓存。

本地 PDF 的正文连接独立于摘要引导：即使关闭摘要，检测到属于同一段落的文本区域仍一起送给模型，按各区域返回译文。请求包含完整段落及原分区，帮助恢复 `util-` / `ity` 这样的边界断词。公式、数字标记带有区域编号，不能在分区间互换；成功分区及时缓存，修复请求只重试失败分区。连续正文组合参与缓存识别，避免复用缺少该段上下文的旧译文。排版仍使用每个原文本区域，保留原页尺寸和图形。

字体不同不表示段落不同：同行的粗体小标题和普通正文会先合成完整文字行。跨页正文可以越过页顶图片和图注继续；独立公式以原文作为只读上下文，不进入待翻译分区。段落结束判断也检查受保护公式中原有的句末标点，避免把已经结束的公式句子误接到下一段。
