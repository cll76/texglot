# 能力边界与排错

[English](troubleshooting.md) · **简体中文** · [返回 README](../README_CN.md)

TeXGlot 支持 **LaTeX 源码和本地文字 PDF**。arXiv PDF 链接用于识别并下载论文源码；本地 PDF 从可提取文字的区域生成译文，尽量保留版式、图片和公式，扫描文档需要先做 OCR。PDF 输入不需要 TeX 编译器，也不生成 LaTeX 源码。Zotero 插件当前仍只提交 arXiv 或 LaTeX 来源。

| 情况 | 检查方向 |
| :--- | :--- |
| arXiv 导入失败 | 确认论文提供可下载的 TeX 源码，且本机可以连接 arXiv。 |
| 本地 PDF 导入失败 | 确认文件未损坏、未加密且有可提取文字。纯扫描版先做 OCR。 |
| PDF 译文放不下 | 原文本区域最多适度缩小字号，仍放不下则保留原文并报告部分完成。 |
| EPS 插图 | 安装可选的 Ghostscript 后继续任务，程序会保留 EPS 原图并生成供编译使用的 PDF 副本。详见[桌面指南](desktop_CN.md)。 |
| PSTricks／PostScript 绘图 | 默认 Tectonic 安装包不包含完整 PostScript 工具链，建议先转换为 PDF 插图。另装完整 TeX 时还需匹配的输出驱动与外部工具，并检查图形是否实际显示，不能仅依据退出状态。 |
| 编译失败 | 补齐 `.sty`、图片与参考文献，查看编译日志；依赖 shell escape 或缺失外部工具的模板可能不适用。设置中可以选择已安装的 XeLaTeX/LuaLaTeX。 |
| `sandbox_apply: Operation not permitted` | 服务若由受限的开发工具启动，macOS 可能拒绝创建编译沙箱。停止该服务，在系统 Terminal 中运行 `bash start-texglot.command`，再继续已有任务。程序保留编译隔离，不自动改为无沙箱编译。 |
| API 报错 | 检查地址、地域、模型权限、余额和限流；必要时降低并发或增加超时。 |
| 部分文字未翻译 | 检查任务警告，继续任务以重试失败段落。未知宏、作者信息和参考文献条目可能按规则保留原文。 |
| 原文和译文页数不同 | 翻译会改变文字长度和分页。优先按共同内容定位点同步，缺少定位点时退回页内位置；并非逐句对齐。 |
| 源码安装在前端构建阶段超时 | 本地构建超过 10 分钟会停止。检查输出；若目录访问卡住，将源码解压到普通本地项目目录后重新安装。依赖下载不受该构建超时限制。 |
| 找不到 `texglot` | 运行 `uv tool update-shell` 后重开终端，或在源码目录使用 `uv run python -m app.cli`。 |

图片及矢量图内文字保留原文，不做 OCR 翻译或重绘；图外正文和图注仍会翻译。科研使用仍需人工检查译文，自动校验不代表每一句语义都正确。
